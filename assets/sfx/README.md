# Sound effects

Everything here is **built** by `tools/sfx_build.py` from CC0 Freesound previews: it downloads the sources, cuts
the takes, bakes in pitch, normalizes, fades, encodes mp3 and writes `sfx_v1.json` and the credits below. To change
a sound, edit its line in `RECIPE` there and rerun (setup is in the script's docstring). `tools/sound_shortlist.html`
(served at /tools/sound_shortlist.html locally) is the audition page of all the candidates that were considered.
A slot with no files falls back to the synthesized sound in `index.html`.

## Manifest

Each slot is a list of **variants** (one is picked at random each play, never the same one twice in a row):

```json
"raptor.chirp": ["raptor/chirp_goose_01.mp3", "raptor/chirp_goose_02.mp3", "raptor/chirp_goose_03.mp3"]
```

Or a list of **layers** played together, each with its own variants. Layers are how you build a creature
out of real animals, the way the Jurassic Park sound designers did:

```json
"rex.roar": [
  { "files": ["rex/roar_elephant_01.mp3", "rex/roar_elephant_02.mp3"], "rate": [0.72, 0.8] },
  { "files": ["rex/roar_tiger_01.mp3"], "gain": 0.6, "rate": [0.6, 0.66], "delay": 0.08 },
  { "files": ["rex/roar_alligator_01.mp3"], "gain": 0.4, "rate": [0.8, 0.9] }
]
```

- `rate`: playback speed range [lo, hi]. Below 1 is lower and slower (bigger animal). Default is a small random wobble.
- `gain`: layer volume (the slot also has a base gain in `SLOTS` in index.html).
- `delay`: seconds after the sound starts.

Try a sound from the browser console: `game.hear('rex.roar', 20)` plays it 20 m in front of you,
`game.hear('rifle.shot')` at your ear. `game.sfx()` shows how many files loaded per slot.

## Slots

| slot | when it plays | what to look for |
|---|---|---|
| `rifle.shot` | every shot (also your partner's, placed in the world) | close, punchy rifle report, **trimmed tight to the transient** |
| `rifle.mech` | with your own shot | action clack / bolt cycling, short |
| `rifle.tail` | with every shot | outdoor echo / distant rumble tail, 1–2 s |
| `rifle.dry` | trigger on an empty mag | dry-fire click |
| `rifle.magout` / `rifle.magin` | reload, 0 s and 0.6 s | magazine release / insert |
| `rifle.bolt` | end of reload (~1.4 s) | charging handle / bolt rack |
| `hit.body` / `hit.head` | you hit a dino | meaty thwack / sharper crack or tick |
| `player.hurt` | you get bitten | grunt or impact |
| `player.heart` | low health, repeats | a single heartbeat |
| `raptor.chirp` | raptor stalking, every 3–7 s | goose honks, bird screeches, pitched chatter |
| `raptor.screech` | raptor spots you and charges | horse/dolphin/eagle screams, layered |
| `raptor.bite` / `rex.bite` | the bite lands | jaw snap, hiss, crunch |
| `raptor.death` / `rex.death` | killed | pained collapse call |
| `rex.growl` | rex stalking, every 3–7 s | low rumble: alligator, lion, tiger, pitched down |
| `rex.roar` | rex spots you | the big one: elephant + tiger + alligator, pitched down |
| `rex.step` | each rex footfall | deep boom (kick-drum-ish), the screen shakes too |
| `body.fall` | a dino hits the ground | heavy body thud (played slower for the rex) |
| `amb.forest` | loops all game | forest wind / birds bed, seamless loop |
| `amb.stream` | loops, louder near the water | creek / brook, seamless loop |

## Formats and caching

- Use **.mp3** (or .m4a): every browser decodes them. Mono is fine for everything except the ambience loops.
- Trim silence off the front: any gap there is latency on the trigger.
- Files are cached forever (`_headers`), so **never overwrite a file in place**: give a changed sound a new name.
  The manifest is versioned: to ship a changed manifest, copy it to `sfx_v2.json` and bump `SFX_V` in index.html.

## Where to find sounds

- **Sonniss GDC Game Audio Bundle** (sonniss.com/gameaudiogdc): free, royalty-free, no attribution. Every year's
  bundle has professional weapon and creature libraries. Best source for the rifle.
- **Freesound.org**: filter by license "Creative Commons 0". Search real animals, not "dinosaur".
- **Pixabay sound effects**: free license, no attribution.
- Avoid CC-BY-NC (non-commercial) and anything without a clear license.
